# 3-Query SERP Closeout

This is the final pre-build SERP pass. Do not add `Happy Wheels guide` / `Happy Wheels wiki` scans.

## Query 1 — `Happy Wheels Steam`

**Role:** Brand query  
**Competition:** Medium  
**Observed result types:** SteamDB, large Reddit announcement threads, fresh release/news pages.  
**Dedicated 2026 Steam guide domain:** Not observed.  
**Decision:** Own with `/steam-release/` + homepage, but do not assume brand SERP is empty.

## Query 2 — `Happy Wheels Steam Workshop`

**Role:** Strongest player problem  
**Competition:** Low specialist competition / high accuracy gap  
**Observed result types:** Reddit demand/speculation, generic launch coverage, at least one unsupported article claiming Workshop.  
**Official fact:** Steam page confirms Level Editor + Level Browser + 5M+ levels; it does not confirm Steam Workshop.  
**Decision:** Launch `/steam-workshop/` as a dated status/clarification page.

## Query 3 — `Happy Wheels Steam old account levels`

**Role:** Second strongest player problem  
**Competition:** Low  
**Observed result types:** Reddit questions about account sync/community preservation; no clean official answer page.  
**Official fact:** 5M+ community levels are confirmed. Personal TotalJerkface account/favorites/history migration is not.  
**Decision:** Launch `/steam-account-levels/` as a boundary/compatibility-status page.

## Final BUILD decision

**BUILD remains justified.**

The opportunity is not a generic Happy Wheels wiki. It is a narrow Steam-2026 problem site whose first pages answer the exact questions current SERPs handle poorly.
