This page is a fictional combat primer for Example Game. It exists to exercise the default article layout: title, description, headings, table of contents, notes, a table, an image placeholder, and internal links.

## Core loop

Players scout a district, pick a loadout, and resolve encounters with timing and positioning rather than raw stats.

### Scouting

Mark a route before committing. Safer paths trade time for fewer surprise fights.

### Loadouts

Each run starts with one primary tool and one support tool. Swapping mid-run is allowed at benches.

## Timing windows

:::note
This is a Starlight aside. Use notes for rules that are easy to miss in a longer paragraph.
:::

Heavy attacks can be canceled during the first third of the swing. After that point, the animation locks until recovery.

:::tip[Starter tip]
If a guard break fails, dash sideways instead of reversing. The recovery is shorter.
:::

## Tool comparison

| Tool | Role | Best used when |
| --- | --- | --- |
| Ember Hook | Gap closer | Crossing ledges or pulling a target off cover |
| Glass Lantern | Reveal | Checking dark rooms before entering |
| Quiet Chime | Crowd control | Two or more enemies share a lane |
